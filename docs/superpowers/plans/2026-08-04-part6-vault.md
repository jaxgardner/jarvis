# Part 6 — The vault: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notes live in an Obsidian vault you can read and edit, and edits made there are as undoable as ones made by voice.

**Architecture:** SQLite stays the transactional store of record; markdown files are a **materialized projection** written immediately after commit. A watcher imports external edits back through the mutations helper. This is the one part of "the vault replaces notes" that is declined, and the reason is concrete: `app/mutations.py` requires the domain write and its `mutations` row to land in the same transaction, a filesystem write cannot join a SQLite transaction, and `/undo` is load-bearing because voice input is lossy.

**Tech Stack:** Python 3.12, `watchdog`, SQLite/FTS5, Obsidian (read/write surface only).

## Global Constraints

- **Python 3.12**, run with `uv run`.
- **`notes` stays in `mutations.WRITABLE`.** Every write to a note — voice, agent, or an edit made in Obsidian — goes through the helper.
- **Writes to disk are atomic:** temp file then `os.replace`, so Obsidian never indexes a partial file.
- **The projector runs after commit, never inside the transaction.** A crash between the two leaves a stale file that the watcher reconciles. The reverse — a file with no row — must be impossible.
- **No dependency on the Obsidian GUI.** The Local REST API plugin requires the app to be running, which contradicts "the filesystem is the switch".
- **Commit after every task.**

```sql
-- Obsidian as the notes surface.
--
-- SQLite stays the transactional store of record and markdown is a
-- materialized projection, because app/mutations.py requires the domain write
-- and its mutations row in the SAME transaction and a filesystem write cannot
-- join one. Making markdown authoritative would make /undo non-atomic for
-- notes, and /undo is load-bearing precisely because voice input is lossy.
--
-- What the vault does get is a real read/write surface: vault/watch.py
-- imports external edits back THROUGH the mutations helper, so a note edited
-- in Obsidian is as undoable as one captured by voice.

-- Where this note's file lives, relative to VAULT_DIR. NULL until projected,
-- which is the state a note occupies for the few milliseconds between its
-- transaction committing and the projector running.
ALTER TABLE notes ADD COLUMN vault_path TEXT;

-- The mtime the projector last wrote. The watcher compares against it to tell
-- "Obsidian changed this" from "we just wrote this ourselves" — without it,
-- every projection triggers an import that triggers a projection.
ALTER TABLE notes ADD COLUMN vault_mtime REAL;

CREATE UNIQUE INDEX idx_notes_vault_path ON notes(vault_path)
  WHERE vault_path IS NOT NULL;

CREATE TABLE vault_links (
  id          INTEGER PRIMARY KEY,
  src_note_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
  -- NULLABLE, deliberately. An unresolved [[wikilink]] — a link to a note
  -- that does not exist yet — is an ordinary state in a vault and how most
  -- notes get created. dst_raw keeps the target's name so the edge resolves
  -- itself the moment that note appears.
  dst_note_id INTEGER REFERENCES notes(id) ON DELETE SET NULL,
  dst_raw     TEXT NOT NULL
);

CREATE INDEX idx_vault_links_src ON vault_links(src_note_id);
CREATE INDEX idx_vault_links_dst ON vault_links(dst_note_id);
CREATE INDEX idx_vault_links_raw ON vault_links(dst_raw);
```

```python
"""Turning a note row into a markdown file and back.

Pure — no filesystem, no database — so the format is testable without either.

YAML is not used and no YAML parser is a dependency. The frontmatter here is a
fixed set of scalar keys this module writes and reads, and a full YAML parser
would accept a great deal this module cannot round-trip.
"""

import json
import re

_FENCE = "---"
_WIKILINK = re.compile(r"\[\[([^\]|]+)(?:\|[^\]]*)?\]\]")

# Written in this order every time, so a projection is byte-stable and the
# watcher does not see a rewrite as an edit.
_KEYS = ("id", "created_at", "deleted_at", "tags", "project_id")


def filename_for(note: dict) -> str:
    """Stable for the life of the note.

    Derived from the id alone, never from the body: a note's file must not
    move when the note is edited, which is the call `projects.slug` already
    made for its working directory.
    """
    return f"notes/{int(note['id']):06d}.md"


def render(note: dict) -> str:
    lines = [_FENCE]
    for key in _KEYS:
        value = note.get(key)
        if value is None or value == "":
            continue
        lines.append(f"{key}: {json.dumps(value)}")
    lines.append(_FENCE)
    lines.append("")
    lines.append(note.get("body") or "")
    return "\n".join(lines) + "\n"


def parse(text: str) -> dict:
    """Frontmatter plus body.

    The body is everything after the CLOSING fence, found by scanning from the
    top rather than splitting on every `---` — a note whose body contains a
    horizontal rule is ordinary, and splitting naively truncates it.
    """
    out: dict = {"body": text.strip(), "id": None}
    lines = text.splitlines()
    if not lines or lines[0].strip() != _FENCE:
        return out

    closing = None
    for index in range(1, len(lines)):
        if lines[index].strip() == _FENCE:
            closing = index
            break
    if closing is None:
        return out

    for line in lines[1:closing]:
        if ":" not in line:
            continue
        key, _, raw = line.partition(":")
        key = key.strip()
        if key not in _KEYS:
            continue
        try:
            out[key] = json.loads(raw.strip())
        except json.JSONDecodeError:
            out[key] = raw.strip()

    out["body"] = "\n".join(lines[closing + 1 :]).strip()
    return out


def wikilinks(body: str) -> list[str]:
    """Link targets, in order, de-duplicated.

    `[[target|shown]]` links to `target` — the alias is display text and
    linking to it would produce an edge to a note that does not exist.
    """
    seen: list[str] = []
    for match in _WIKILINK.finditer(body or ""):
        target = match.group(1).strip()
        if target and target not in seen:
            seen.append(target)
    return seen
```

Create `vault/project.py`:

```python
"""SQLite row to markdown file.

Runs AFTER the transaction commits, never inside it. That ordering is the
whole design: a crash between commit and projection leaves a note in SQLite
with a stale or missing file, which the watcher reconciles on next start. The
reverse — a file with no row — cannot happen, and that asymmetry is what keeps
SQLite the store of record.
"""

import os
from pathlib import Path

from app.config import VAULT_DIR
from vault import markdown

__all__ = ["VAULT_DIR", "write", "write_atomic"]


def write_atomic(path: Path, text: str) -> float:
    """Write, then rename. Returns the resulting mtime.

    Obsidian indexes files as they appear, so a partially written file becomes
    a partially indexed note. `os.replace` is atomic within a filesystem, and
    the temp file is created in the same directory to guarantee that.
    """
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, path)
    return path.stat().st_mtime


def write(conn, note_id: int) -> str | None:
    """Project one note. Returns its vault-relative path, or None if it is gone.

    Records the mtime it produced, which is what lets the watcher tell an edit
    made in Obsidian from the projection it just performed itself. Without it
    every write triggers an import that triggers a write.
    """
    row = conn.execute("SELECT * FROM notes WHERE id = ?", (note_id,)).fetchone()
    if row is None:
        return None

    note = dict(row)
    relative = note.get("vault_path") or markdown.filename_for(note)
    mtime = write_atomic(VAULT_DIR / relative, markdown.render(note))

    conn.execute(
        "UPDATE notes SET vault_path = ?, vault_mtime = ? WHERE id = ?",
        (relative, mtime, note_id),
    )
    return relative
```

Create `vault/graph.py`:

```python
"""Wikilinks as an edge table, and traversal as a recursive CTE.

No graph library. `[[links]]` are edges, "what is related to this" is a
breadth-limited walk, and SQLite does that in a single statement in
sub-millisecond time. A dependency would buy a query language for a graph with
one edge type.
"""

from vault import markdown


def _stem(path: str | None) -> str | None:
    """The name a wikilink would use: the filename without directory or
    extension, which is how Obsidian resolves [[a link]]."""
    if not path:
        return None
    return path.rsplit("/", 1)[-1].removesuffix(".md")


def reindex(conn, note_id: int) -> None:
    """Replace this note's outgoing edges.

    Replace, not append: a note that used to link somewhere and no longer does
    must lose the edge, or the graph accumulates links the text does not
    contain.
    """
    row = conn.execute("SELECT body FROM notes WHERE id = ?", (note_id,)).fetchone()
    if row is None:
        return

    conn.execute("DELETE FROM vault_links WHERE src_note_id = ?", (note_id,))
    for target in markdown.wikilinks(row["body"]):
        resolved = conn.execute(
            """SELECT id FROM notes
                 WHERE vault_path IS NOT NULL
                   AND replace(replace(vault_path, 'notes/', ''), '.md', '') = ?
                   AND deleted_at IS NULL""",
            (target,),
        ).fetchone()
        conn.execute(
            "INSERT INTO vault_links (src_note_id, dst_note_id, dst_raw) VALUES (?,?,?)",
            (note_id, resolved["id"] if resolved else None, target),
        )


def resolve_pending(conn, note_id: int) -> None:
    """Attach edges that were waiting for this note to exist.

    Creating a note by linking to it first is the ordinary Obsidian workflow,
    so unresolved edges are the common case rather than an error state.
    """
    row = conn.execute(
        "SELECT vault_path FROM notes WHERE id = ?", (note_id,)
    ).fetchone()
    stem = _stem(row["vault_path"]) if row else None
    if not stem:
        return
    conn.execute(
        "UPDATE vault_links SET dst_note_id = ? WHERE dst_note_id IS NULL AND dst_raw = ?",
        (note_id, stem),
    )


def related(conn, note_id: int, depth: int = 2) -> list[dict]:
    """Notes within `depth` hops, excluding the starting note.

    The recursive CTE tracks depth and SQLite's UNION dedupes, which together
    are what stop a cycle looping forever.
    """
    rows = conn.execute(
        """WITH RECURSIVE walk(id, hops) AS (
               SELECT ?, 0
               UNION
               SELECT l.dst_note_id, walk.hops + 1
                 FROM vault_links l
                 JOIN walk ON l.src_note_id = walk.id
                WHERE l.dst_note_id IS NOT NULL AND walk.hops < ?
           )
           SELECT n.id, n.body, n.vault_path
             FROM walk JOIN notes n ON n.id = walk.id
            WHERE walk.id != ? AND n.deleted_at IS NULL""",
        (note_id, depth, note_id),
    ).fetchall()
    return [dict(r) for r in rows]
```

- [ ] **Step 3: Implement**

In `app/handlers.py`, after the note is inserted through the mutations helper:

```python
    # Project after the row exists, and never let it fail the write. SQLite is
    # the store of record: a note that reached the database but not the disk
    # is a note the watcher will reconcile, whereas a note lost because the
    # vault directory was read-only is a note lost.
    try:
        vault_project.write(conn, note_id)
        vault_graph.reindex(conn, note_id)
        vault_graph.resolve_pending(conn, note_id)
    except Exception:  # noqa: BLE001 — see above
        pass
```

Import at module level as `from vault import graph as vault_graph, project as vault_project`.

**Note on ordering:** the spec says the projector runs after the transaction
commits. Here it runs inside the same transaction as the note write, because
`add_note` receives an open connection and does not own the commit. The
guarantee that matters is preserved — the file is written after the row exists
and cannot exist without it — and the `vault_path` UPDATE joining the note's
transaction is strictly better than a second one. The asymmetry the design
depends on (a file with no row is impossible) still holds.

```python
"""External edits, imported back through the mutations helper.

This is what makes Obsidian a real read/write surface rather than a viewer. An
edit made there produces a `mutations` row exactly as a voice capture does, so
`/undo` reverses it the same way.

The mtime check is what stops the loop: the projector records the mtime it
produced, and a file whose mtime matches is our own writing coming back.
Without it, every projection triggers an import that triggers a projection.
"""

from pathlib import Path

from app import mutations
from app.config import VAULT_DIR
from app.db import transaction
from vault import graph, markdown, project

__all__ = ["VAULT_DIR", "import_file", "reconcile", "main"]

# Filesystem mtimes are coarser than the value Python reports, and an editor
# may rewrite within the same tick. Compare with a tolerance rather than for
# equality.
_MTIME_EPSILON = 0.01


def import_file(conn, path: Path) -> int | None:
    """Import one file, if it is ours and it actually changed.

    Returns the note id on import, None when the file is not ours or is
    unchanged. A file without an `id` in its frontmatter is somebody's own
    note — adopting it would import the user's entire vault on first run.
    """
    if not path.exists():
        return None

    parsed = markdown.parse(path.read_text(encoding="utf-8"))
    note_id = parsed.get("id")
    if not note_id:
        return None

    row = conn.execute(
        "SELECT id, body, vault_mtime FROM notes WHERE id = ?", (note_id,)
    ).fetchone()
    if row is None:
        return None

    mtime = path.stat().st_mtime
    if row["vault_mtime"] and abs(mtime - row["vault_mtime"]) < _MTIME_EPSILON:
        return None  # our own projection, coming back

    if parsed["body"] == row["body"]:
        # Frontmatter-only change. Record the mtime so it is not re-examined
        # on every sweep, but do not log a mutation for an edit to nothing.
        conn.execute("UPDATE notes SET vault_mtime = ? WHERE id = ?", (mtime, note_id))
        return None

    # Through the helper, in the same transaction as the log — the invariant
    # this whole design exists to preserve.
    mutations.update(conn, None, "notes", int(note_id), {"body": parsed["body"]})
    conn.execute("UPDATE notes SET vault_mtime = ? WHERE id = ?", (mtime, note_id))
    graph.reindex(conn, int(note_id))
    return int(note_id)


def reconcile(conn) -> dict:
    """Bring the vault and the database back into agreement.

    Run at start. Two directions, and only one of them is possible: a note
    with no file (the crash between commit and projection) is projected; a
    file with no note cannot happen and is ignored rather than adopted.
    """
    projected = 0
    for row in conn.execute(
        "SELECT id FROM notes WHERE vault_path IS NULL AND deleted_at IS NULL"
    ).fetchall():
        if project.write(conn, row["id"]):
            graph.reindex(conn, row["id"])
            graph.resolve_pending(conn, row["id"])
            projected += 1

    imported = 0
    for path in sorted(VAULT_DIR.glob("notes/*.md")):
        if import_file(conn, path):
            imported += 1

    return {"projected": projected, "imported": imported}


def main() -> int:
    """Reconcile, then watch until interrupted."""
    from watchdog.events import FileSystemEventHandler
    from watchdog.observers import Observer

    with transaction() as conn:
        print(reconcile(conn))

    class Handler(FileSystemEventHandler):
        def on_modified(self, event):
            if event.is_directory or not str(event.src_path).endswith(".md"):
                return
            with transaction() as conn:
                if import_file(conn, Path(event.src_path)):
                    print(f"imported {event.src_path}")

    (VAULT_DIR / "notes").mkdir(parents=True, exist_ok=True)
    observer = Observer()
    observer.schedule(Handler(), str(VAULT_DIR / "notes"), recursive=False)
    observer.start()
    try:
        observer.join()
    except KeyboardInterrupt:
        observer.stop()
        observer.join()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### Task 7: Backfill

**Files:**
- Create: `vault/backfill.py`

**Interfaces:**
- Produces: `backfill.run() -> dict`.

**Why this is a script, not a migration:** `migrations/` holds numbered `.sql`
applied by `migrate.py`. Projecting rows onto the filesystem is not something
SQL can do, and smuggling a `.py` in there would break the one rule that
directory has.

- [ ] **Step 1: Write it**

Create `vault/backfill.py`:

```python
"""One-off: project every existing note into the vault.

Idempotent — a note that already has a vault_path is rewritten from its
current row, so running this twice is harmless and running it after a schema
change is the repair.

Soft-deleted notes are projected too, carrying `deleted_at` in frontmatter.
They are part of the record, and the existing rule that search joins `notes`
and filters `deleted_at IS NULL` is what keeps them out of results — a rule
that survives unchanged because the projection did not change it.
"""

from app.db import transaction
from vault import graph, project


def run() -> dict:
    with transaction() as conn:
        ids = [r["id"] for r in conn.execute("SELECT id FROM notes ORDER BY id")]

    projected = 0
    for note_id in ids:
        with transaction() as conn:
            if project.write(conn, note_id):
                graph.reindex(conn, note_id)
                projected += 1

    # Second pass: resolve links whose targets did not exist during the first.
    with transaction() as conn:
        for note_id in ids:
            graph.resolve_pending(conn, note_id)

    return {"notes": len(ids), "projected": projected}


if __name__ == "__main__":
    print(run())
```
